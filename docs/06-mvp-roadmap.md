# MVP Roadmap

## MVP 0 — Personal prototype

Goal:
Build a working personal agent over Telegram with structured goals/events and basic guardian mode.

Features:
- Telegram bot
- OpenAI LLM response
- Postgres DB
- Prisma schema
- user profile
- goal CRUD
- event registry
- event extraction from chat
- manual check-ins
- basic risk engine
- daily review
- weekly review

No:
- WhatsApp
- full OpenClaw integration
- mobile app
- complex OAuth
- automatic health data
- trading execution
- private keys
- withdrawals
- full dashboard

## MVP 1 — Technical alpha

Add:
- GitHub fetcher
- Gmail fetcher
- wallet public-address fetcher
- integration registry
- memory viewer
- basic web settings page
- custom event types
- templates for goals

## MVP 2 — Product alpha

Add:
- WhatsApp/OpenClaw channel adapter
- OAuth flows
- health integrations
- dashboard
- billing
- multi-user isolation
- enterprise/fund version
